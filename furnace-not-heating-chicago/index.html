Furnace Not Heating in Chicago? Start With These Checks

If your furnace is running but the house is not warming up, start with the simple items: confirm the thermostat is set to heat, make sure the temperature setting is above the room temperature, check that the furnace has power, and look at the air filter.

When to request help

If the furnace will not start, repeatedly shuts down, smells unusual, or the basic checks do not solve the problem, stop troubleshooting and request professional service.
