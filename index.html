Before requesting service

1. Thermostat set to HEAT.

2. Fan set to AUTO, not ON.

3. Replace thermostat batteries if the display is weak, blank or overdue.

4. Check the furnace filter. Replace it if it is visibly dirty and you can do so safely.

5. Check the furnace switch or breaker only if it is safe and accessible.

Stop if you smell gas, suspect an electrical burning odor, or a carbon-monoxide alarm sounds. Follow emergency/utility guidance instead of continuing DIY checks.

Common questions

What should I check before requesting furnace help?

Start with the simple items: make sure the thermostat is set to Heat, set the fan to Auto, replace thermostat batteries if needed, check the furnace filter, and check the furnace switch or breaker only if it is safe and accessible.

Can a dirty furnace filter cause heating problems?

Yes. A heavily restricted filter can reduce airflow and contribute to overheating, short cycling, weak airflow, or a furnace that runs without heating normally. If the filter is visibly dirty, replacing it is a reasonable first check.

When should I stop troubleshooting and request help?

Request help when the basic thermostat, battery, filter, power and airflow checks do not restore normal heat, or when the furnace repeatedly shuts down, makes new loud noises, or produces unusual odors.

What if I smell gas or a carbon-monoxide alarm sounds?

Do not use this website as emergency troubleshooting. Leave the area and follow your gas utility or emergency-service guidance. A carbon-monoxide alarm or suspected gas leak needs immediate safety action.
